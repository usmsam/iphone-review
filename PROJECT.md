# iphone-review

## Суть
Промо-лендинг товара (iPhone 12) с блоком кросс-продаж: презентация устройства и подборка сопутствующих товаров, подгружаемых из локальной базы (JSON). Вёрстка продающей страницы с интерактивом на чистом JS.

## Стек
- **Vanilla JS** + HTML + CSS (без сборки).
- Мини-библиотека меню `amenu`, скрипты скролла.
- Данные кросс-продаж — `cross-sell-dbase/dbase.json`.

## Архитектура
- `iphone/index.html` — страница лендинга.
- `iphone/js.js`, `iphone/scripts/scroll.js` — интерактив и скролл.
- `iphone/libs/amenu/*` — подключаемое меню.
- `iphone/cross-sell-dbase/dbase.json` — каталог сопутствующих товаров.

## Фичи
- **Презентация товара:** секции лендинга iPhone 12.
- **Кросс-продажи:** вывод сопутствующих товаров из JSON (напр. «Яндекс.Станция»).
- **Интерактив:** меню и скролл-эффекты.

## Сложные места
- **Кросс-селл из данных.** Рендер подборки сопутствующих товаров из `dbase.json` — отделение данных от разметки на чистом JS.
- **Вёрстка продающей страницы.** Секционный лендинг с подключаемыми библиотеками без фреймворка.

## Кейсы
- **«Кросс-продажи на лендинге из JSON».** Как подгружать и рендерить сопутствующие товары без бэкенда.
- **Статус: до ИИ.**

## Навыки
